Fair.io - The fairest .io team-based game!

Get ready for the fairest .io team-based game! Fight enemies, gain XP, obtain great upgrades and get ready for the boss fight!


Controls
- Move with WASD or the Arrow Keys!

- Browse menus, aim and attack with the mouse!


Credits
This game was made by D2_Lx0wse and Hypah for the Brackeys GameJam 2026.2 with the theme "Trust no one".

The game is written in C++ using raylib.

The random.h library was taken from learncpp.com

How to build
The game was built on Visual Studio 2022 on C++ 20.
To build the game, you must include "raylib-6.0_win64_msvc16" in the "brackeys" folder.
